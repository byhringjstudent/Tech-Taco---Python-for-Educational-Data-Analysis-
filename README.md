# Tech-Taco Python for Educational Data Analysis

A beginner-friendly Python project that uses data analysis techniques to explore educational datasets. This repository helps learners practice data cleaning, exploratory analysis, visualization, and interpretation in the context of student performance, attendance, assessment outcomes, and classroom trends.

## Overview

This project supports learning how to work with educational data using Python tools and libraries. It is intended for students, educators, and aspiring data analysts who want to understand how data can answer questions about learning outcomes, engagement, and school performance.

## Goals

- Analyze educational datasets with Python
- Practice real-world data cleaning and preparation
- Explore patterns in student and classroom data
- Build clear visualizations and summaries
- Communicate findings in a useful and understandable way

## Skills Covered

- Reading data from .sav files (we may cover .xlsx and .csv files as well)
- Data cleaning and preprocessing
- Descriptive statistics
- Exploratory data analysis
- Data visualization with Python libraries such as Matplotlib
- Identifying trends and insights from educational data

## Getting Started

### Prerequisites

- Python 3.10 or newer
- Access to the Internet
